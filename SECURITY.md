# Security scope

Educational loopback lab using authorized data. No production monitoring service or security guarantee is provided. Default demo mode sends no queries and performs no live capture or system blocking.

Do not post captures, browsing data, internal addresses, credentials, or original identifiers in public issues. If the repository owner enables private vulnerability reporting, use it for sensitive findings; otherwise ask for a private contact without publishing sensitive content. No monitored mailbox or response SLA is claimed.

Keep runtime data private. Review the complete staged contents and any imported Git history before publication. The supplied publication guard detects only a limited set of private/generated artifacts and credential patterns.
